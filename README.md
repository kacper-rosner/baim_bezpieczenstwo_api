## Zadania: 

### If you want, you can go through exercises with the help from us - we're doing a walkthrough for some problems on the screen 

### Install node.js version >=26.00 

#### Add node.js to PATH variable !!

### Run git clone https://github.com/juice-shop/juice-shop.git --depth 1 
### Go into the cloned folder with cd juice-shop
### Run npm install (only has to be done before first start or when you change the source code)
### Run npm start
### Browse to http://localhost:3000
